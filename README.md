## Key Features

- **Manual Mod Selector**: Direct local mod file selection dialog (`.jar`, `.zip`, `.thunder-mods`, `.mrpack`) with parallel multi-file import and automated dependency resolution.
- **Light & Dark Theme Engine**: High-contrast, elegant White / Slate theme alongside the signature dark mode with one-click titlebar toggle and system auto-sync.
- **Global Multi-Language (i18n) Engine**: Seamless multi-language support (English, Turkish, German, Spanish, French, Russian, Chinese, Japanese, and more) with automatic OS system language detection.
- **Multi-Loader Support**: Native support for Vanilla, Fabric, Quilt, Forge, and NeoForge.
- **CurseForge & Modrinth Engine**: 1-click mod install, automated dependency resolution, and personal CurseForge Eternal API key support.
- **.thunder-mods Package Manager**: 1-click export and installation of `.thunder-mods` mod bundles.
- **Drag & Drop Async Mod Installer**: Instant concurrent mod installation for `.zip`, `.thunder-mods`, and `.jar` files with automated dependency resolution.
- **Dedicated Server Host Management**: Local Paper, Purpur, Spigot, Fabric, and Forge server manager with web console.
- **Advanced Skin & Cape Engine**: Zero-hijack offline skin protection, canonical Steve/Alex fallback, and global cape network.
- **Automatic Background Updates**: Seamless background updater via GitHub Releases.
